# Bundesliga FDR

Fixture Difficulty Rating tool for the German Bundesliga. Set each team's strength (1-5, 1-5 in
half steps, or 1-10) and instantly see how that colors the difficulty of every team's upcoming
fixtures.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Ready to host on Vercel (`vercel.json` includes an SPA rewrite to `index.html`).
